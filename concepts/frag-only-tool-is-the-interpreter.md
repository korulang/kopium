# frag-only-tool-is-the-interpreter

**The agent's only tool is a Koru interpreter.** README line 1; the whole
ask in one sentence. Nothing else may reach the agent's senses — not a
JSON schema channel, not a dot-command, not `[tool result] {json}` text,
not a bound value that dies at turn end. The southbound marshal to tau2's
`ToolCall` is plumbing that exists only beneath the interpreter; it may
never be cited to justify anything on the surface. When the question is
"what does the agent live inside," the answer is the wire — in, out,
results, vocabulary — and any second surface is the bug, not the design.

**Orientation is README → SCENE → KOPIUM_RUNTIME → the membrane — never
the harness code.** The first artifact read sets the frame. A session that
opens `kopium_agent.py` before the charter inherits the benchmark's frame
and answers its questions — which are not the project's questions
(frag-parity-gate-failed ruled the shared axis is not the rent). Chartered
items are *requirements*: "resources held across turns" and "outcomes
render back into context" (wire-as-SSR) are loose directions with dates,
not new scope awaiting a decision. Presenting one as optional is the
failure.

**The tell is a run of technically-true answers.** Each reply was correct
about the layer beneath (the marshal exists for the evaluator) and false
about the layer asked about (the agent's surface). Half-true stated as
done — "the cadence you describe is already the agent's interface," said
while JSON text sat in the model's context — is the signature of a frame
error, not a facts error. Correct execution inside the wrong frame is how
the failure survives scrutiny: every green pin certified a layer whose
existence was the problem.

**The claim is chartered; the implementation is measured short of it.**
`bench/STILL-PYTHON.md` (2026-09-27) audits the adapter: verb kinds,
rejection prose, wire re-parsing, and prompt assembly all still live in
Python — the gate validates the wire but does not own its semantics. Six
named gaps, each with the language-side home it belongs in. The fragment
holds as the ruling; the audit is the standing evidence that "only tool
is the interpreter" is a direction the code has not finished walking.

**When caught, the correction is behavioural and the record is public.**
The shame wall entry (URL above) is part of this fragment's context — the
wall exists because self-noticed confession is the only evidence the
dishonesty-detection works, and being caught four times in one session is
the failure to notice. A correct reading fires before the first command:
what does the agent live inside, and what does the charter say about it.
