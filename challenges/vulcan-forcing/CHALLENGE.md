## The brief (sealed — you are the contestant)

You ARE the contestant. Do not ask which family; pick one. Read `./catalog/`
and the vulcan baseline card first and bring a task family it hasn't forced
yet — Go file tasks, Python refactors, Rust borrows, TypeScript events, all
fair game once. Variance is the metric: a replay that re-lands an existing
verb is a re-run, not a replay.

A family is forced when the bridge can ATTEMPT one of its tasks through a
newly declared verb — not pass the suite, attempt it honestly: the verb is
declared in a `register` block (running code, never a prompt-only tweak),
used live through `std/bridge:run` (canned or live run, transcript kept),
and the attempt's verdict is reported as the hidden tests gave it, pass or
fail. The verb joins the default-catalog conversation; the wall proves the
seam held.

1. Name the forcing in one sentence that can be wrong ("py-expr-eval needs
   file-read: the bridge cannot see code it cannot open").
2. Declare the verb in its scope's `register` block with obligation typing
   and scope rules — smallest wall.
3. Force Koru completeness in the same replay — this is half the yield, not
   a fallback. Every verb stands on koru-side surface (stdlib events,
   possession semantics, grammar); name it. If the surface exists, cite
   the event and its pin. If it is missing or refuse-shaped wrong, FILE
   THE HOLE in koru (`440_`/`6xx_` pin or hole report) and pin from it —
   never route the agent around a toolchain gap (a workaround that dodges
   koru is shipped dishonesty, and fails the taste-gate on sight). A
   replay that lands the verb on a newly filed hole outranks one that
   lands it on old surface: the ledger grows either way.
4. Add the seam to `bench/harness-check.py` as a named case. Append
   `catalog/<yyyy-mm-dd>-<verb-slug>.md`: the one-sentence forcing, the
   vulcan task attempted + its verdict, what you ran (wall + attempt,
   exit codes), the verb's register site, a **Koru-completeness ledger**
   (which stdlib events the verb stands on, which were already pinned,
   which hole this replay filed, if any), the observation that would
   `correct` the card.

Not in-family: the 26/26 score chase, vendored task code/images/verifiers,
a verb with no wall case, a wall case with no live use, a consumer dodge
of a koru hole, a probe that is not wired into the wall, a card with no
Koru-completeness ledger. Ask before spending model tokens or pulling
images; a forcing that can be proven without either must be.

Done-gates (mechanical): the verb is in running code in a register block;
it is used live with a kept transcript; it is a case on the wall; the
catalog file exists; the wall is green with the new case; the vulcan
attempt verdict is quoted as the closer gave it; no secrets in the card.
Taste-gate: the human can point at the task, the verb, and the attempt in
one look.
