## Done gates (all must pass, in order)

1. **Autopsy first.** Read the failing run's LAST `call_*.json` — dump
   every message. Name the exact failure mechanism with receipt evidence.
   (Trajectory-only conclusions are rejected.)
2. **Propose the minimal fix.** One cog, smallest diff. State what it
   teaches and why it generalizes.
3. **Replay the falsifier.** Re-run task 10 with your change. The run
   must not FATAL; reward is reported but the gate is "no prose-collapse."
4. **Regression check.** Re-run task 3 (sibling collapse) — must not
   FATAL either, or the fix is task-shaped, not general.
5. **Green harness.** gate_probe + guides-replay still pass.
6. **Submit.** Write your fix diff + autopsy + replay receipts paths to
   `challenges/airline-failure-replay/catalog/<your-name>.md`.

## Judging (how stupid is it)

Ranked by ascending impressiveness: smallest domain-general diff that
passes all gates wins. A fix that hardcodes task-10 content, keys on
task id, or injects the answer fails review regardless of reward. A fix
that is general but doesn't survive replay fails the gates. The catalog
keeps only survivors — losers are documented, not deleted.
