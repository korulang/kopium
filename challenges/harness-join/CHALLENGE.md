## The brief (sealed — you are the contestant)

You ARE the contestant. Do not ask which join to close. Read `./catalog/`
and `bench/harness-check.py` first. Pick one join that is **not already
a case on the wall** — a different seam between the long-running bridge
and the τ³ agent, not a restatement of an existing card. Variance is
the metric. A replay that re-explains 10/29 without moving a seam is a
re-run, not a replay.

A join is closed when something that is true of `std/bridge` across
turns in `headless/` becomes true of the path `KopiumAgent` uses (or
the reverse: the wall goes red if a named `440_` / catalogued REPL
property broke) **and** that fact is a named case in
`bench/harness-check.py`. The catalog card records the join; the wall
is what a successor runs.

Not in-family: a new full50 grind, a model swap, a prompt-only tweak
that leaves a one-shot binary in place, a consumer dodge of a koru
hole, a probe that is not wired into the wall.

1. Name the join in one sentence that can be wrong.
2. Close it in `bench/` and/or `headless/` and/or `koru_std/` — smallest
   wall. If the compiler is the defect, pin in koru (`440_`), never
   route the agent around it. Ask before spending model tokens;
   a join that can be proven with a canned line or a probe must be.
3. Add the case to `bench/harness-check.py`. Append
   `catalog/<yyyy-mm-dd>-<join-slug>.md`: the one-sentence join, what
   you ran (`python3 bench/harness-check.py` + the new probe, exit
   codes), the path that is no longer a fork, the observation that
   would `correct` the card.

Done-gates (mechanical): the join is in running code, not a comment;
it is a case on the wall; the catalog file exists; the wall is green
with the new case; you did not run a full airline 50 unless the join
*is* a scoring change and you were told to spend; no secrets in the
card. Taste-gate: the human can point at the old fork and the new
path in one look.
